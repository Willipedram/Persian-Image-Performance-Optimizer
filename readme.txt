فشرده‌سازی تصاویر وردپرس و ساخت نسخه‌های WebP با صفحه تنظیمات فارسی.

== Installation ==

1. پوشه افزونه را در مسیر `wp-content/plugins` قرار دهید.
2. افزونه را از بخش «افزونه‌ها» فعال کنید.
3. به «تنظیمات ← بهینه‌سازی تصاویر» بروید.

== Description ==

این افزونه کیفیت خروجی JPEG، WebP و AVIF را کنترل می‌کند و برای تصویر اصلی و اندازه‌های بندانگشتی، فایل WebP جانبی می‌سازد. فایل اصلی دست‌نخورده باقی می‌ماند. نسخه‌های ساخته‌شده هنگام حذف پیوست پاک می‌شوند.
