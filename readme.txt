بررسی سلامت سرور و قابلیت‌های واقعی پردازش تصویر پیش از هرگونه بهینه‌سازی.

== Installation ==

1. پوشه افزونه را در مسیر `wp-content/plugins` قرار دهید.
2. افزونه را از بخش «افزونه‌ها» فعال کنید.
3. به «ابزارها ← سلامت سیستم تصاویر» بروید.

== Description ==

در این نسخه، افزونه فقط نسخه‌های PHP و وردپرس، موتورهای Imagick و GD، codecهای WebP/AVIF/JPEG/PNG، حافظه، محدودیت‌های PHP، Cron، وب‌سرور، فضای دیسک و مجوز پوشه‌ها را گزارش می‌کند. هیچ تصویر یا تنظیم سروری تغییر داده نمی‌شود.

== Changelog ==

= 1.1.0 =
* افزودن ماژول مستقل سلامت سیستم و رابط مدیریت فارسی.
* توقف کامل عملیات بهینه‌سازی تا پایان بررسی قابلیت‌های محیط.

= 1.2.0 =
* افزودن چهار جدول اختصاصی تصاویر، کاربردها، صف کارها و گزارش‌ها.
* افزودن migration نسخه‌دار و repositoryهای مستقل.
* نگهداری اطلاعات هنگام حذف افزونه، مگر با انتخاب صریح کاربر.

= 1.3.0 =
* افزودن اسکن اولیه، افزایشی، ادامه‌پذیر و Batch-based کتابخانه رسانه.
* تشخیص فایل‌های گمشده یا خراب، SVG، GIF متحرک، WebP/AVIF و شفافیت قابل اعتماد.
* افزودن صفحه ساده «اسکن تصاویر» و امکان توقف، ادامه و بررسی مجدد خطاها.

= 1.4.0 =
* افزودن هسته امن پردازش تصویر با اولویت Imagick، ویرایشگر وردپرس و GD.
* افزودن Resize بدون Upscale، Crop صریح، فشرده‌سازی، تغییر فرمت، حفظ Alpha و نرمال‌سازی Orientation.
* افزودن Backup خصوصی، اعتبارسنجی خروجی، نوشتن Atomic و Rollback نسخه قبلی.

= 1.5.0 =
* افزودن تبدیل JPEG/PNG به WebP و JPEG/PNG/WebP به AVIF با کنترل قابلیت سرور.
* افزودن تنظیمات کیفیت، Lossless، Metadata، Copyright و Transparency.
* ثبت تاریخچه حجم قبل و بعد، مقدار صرفه‌جویی و جلوگیری از ترجیح خروجی بزرگ‌تر.

= 1.6.0 =
* افزودن تولید Responsive Variant برای JPEG، WebP و AVIF بدون Upscale.
* بررسی اندازه‌های موجود وردپرس، جلوگیری از Duplicate و کنترل فضای دیسک.
* افزودن تنظیمات Candidate width، حداقل/حداکثر عرض و سقف Variant هر تصویر.
